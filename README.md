# DeFit

Тренування, вага, талія і харчування в одному місці. PWA у стилі DeSave.

- Відкрий сайт на телефоні → «Поділитися» → «На екран Початок».
- Вхід тим самим акаунтом, що й у DeFin / DeSave (Профіль → «Увійти й синхронізувати»).
- Перший запуск бази: виконати `supabase/defit.sql` у Supabase SQL Editor.
